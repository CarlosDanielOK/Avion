
# Sistema de Gestión para Agencia de Turismo – Rumbo Sur

## Trabajo Práctico Obligatorio – Programación Orientada a Objetos

## 1. Descripción del proyecto

El presente proyecto tiene como objetivo analizar, diseñar e implementar un sistema de gestión para la agencia de turismo receptivo **Rumbo Sur**, aplicando los conceptos de Programación Orientada a Objetos (POO).

Actualmente, la agencia administra sus reservas, cupos y pagos mediante planillas, lo que dificulta la organización de la información y el seguimiento de sus operaciones.

La solución propuesta busca centralizar la gestión de tours, salidas programadas, clientes, reservas, pagos, servicios adicionales y liquidaciones, garantizando el cumplimiento de las reglas de negocio establecidas.

## 2. Objetivos del sistema

- Optimizar la administración del catálogo de tours y excursiones.
- Gestionar salidas programadas y controlar la disponibilidad de cupos.
- Registrar clientes, pasajeros y reservas.
- Calcular tarifas según temporada, tipo de pasajero y promociones.
- Administrar señas, pagos, saldos pendientes y cancelaciones.
- Gestionar servicios adicionales.
- Asignar guías y vehículos a las salidas programadas.
- Generar listas de pasajeros.
- Calcular los honorarios de los guías.
- Emitir reportes de ocupación, ventas, ingresos y cancelaciones.

## 3. Tecnologías y herramientas

- **Lenguaje:** Java 17 o superior.
- **Paradigma:** Programación Orientada a Objetos.
- **Modelado:** UML.
- **Principios de diseño:** SOLID.
- **Patrones de diseño:** GRASP.
- **Control de versiones:** Git y GitHub.
- **Persistencia:** Lectura y escritura de archivos.
- **Interfaz:** Consola con menú o interfaz gráfica, a definir por el equipo.
